# Changelog

Todos los cambios notables en este proyecto serán documentados en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/),
y este proyecto se adhiere a [Semantic Versioning](https://semver.org/lang/es/).

## [2.0.0] - 2024-01-XX

### Añadido
- **Sistema de logros** con 8 logros desbloqueables
- **Herramientas interactivas**:
  - Calculadora de peso en otros planetas
  - Calculadora de tiempo de viaje entre planetas
  - Calculadora de edad planetaria
  - Simulador de caída gravitacional
- **Panel de misiones espaciales** con 12 misiones reales
- **Timeline histórica** de exploración espacial (1957-2024)
- **Minimapa** para navegación rápida
- **Estelas orbitales** con desvanecimiento
- **Viento solar** con partículas animadas
- **Zona habitable** visualizada
- **Terminador día/noche** en planetas
- **Estrellas fugaces** aleatorias
- **Atajos de teclado** expandidos (T, H, M)
- **Datos expandidos** por planeta:
  - Densidad
  - Campo magnético
  - Descubridor y año
  - 6 datos curiosos por planeta
- **Quiz mejorado** con 15 preguntas y explicaciones
- **Comparación avanzada** con 5 métricas
- **Velocidades hasta 10x**
- **Indicador de tiempo simulado**
- **Contador de logros** en UI

### Cambiado
- **Rediseño completo** de la interfaz
- **Mejoras visuales** significativas:
  - Nebulosas más ricas
  - Estrellas con parpadeo
  - Colores enriquecidos (3 tonos por planeta)
  - Anillos mejorados para todos los planetas con anillos
- **Optimización de rendimiento** del canvas
- **Mejor responsividad** en móviles
- **Sistema de cámara** mejorado con límites expandidos

### Mejorado
- **Rendimiento**: Optimización del loop de animación
- **Accesibilidad**: Más atajos de teclado
- **UX**: Navegación más intuitiva
- **Datos**: Información más completa y precisa
- **Documentación**: README y guías expandidas

## [1.0.0] - 2024-01-XX

### Añadido
- Visualización interactiva del sistema solar
- 8 planetas con órbitas animadas
- Sol con efectos de brillo y corona
- Cinturón de asteroides
- Panel de información detallada por planeta
- Controles de reproducción (play/pausa)
- Control de velocidad (0.25x - 5x)
- Zoom y paneo con mouse
- Sistema de seguimiento de planetas
- Modo de comparación básico
- Quiz con 10 preguntas
- Datos curiosos navegables
- Atajos de teclado básicos
- Diseño responsive
- Tema oscuro espacial

### Características Técnicas
- React 18 con TypeScript
- Canvas API para renderizado
- Tailwind CSS para estilos
- Vite como build tool
- Animaciones con requestAnimationFrame
- Sistema de cámara 2D
- Gestión de estado con hooks

## Versionado

Este proyecto utiliza [Semantic Versioning](https://semver.org/lang/es/):

- **MAJOR** (X.0.0): Cambios incompatibles con versiones anteriores
- **MINOR** (0.X.0): Nuevas funcionalidades backwards-compatible
- **PATCH** (0.0.X): Correcciones de bugs backwards-compatible
