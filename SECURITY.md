## Reportar una Vulnerabilidad

La seguridad de nuestros usuarios es una prioridad. Si descubres una vulnerabilidad de seguridad, por favor sigue estas pautas:

### Proceso de Reporte

1. **NO abras un issue público** para vulnerabilidades de seguridad
2. Envía un email a **[tu@email.com]** con:
   - Descripción detallada de la vulnerabilidad
   - Pasos para reproducir el problema
   - Impacto potencial
   - Posibles soluciones (si las tienes)
3. Recibirás una confirmación de recepción en 48 horas
4. Trabajaremos contigo para entender y resolver el problema

### Qué Esperar

- **Confirmación**: Recibirás una confirmación en 48 horas
- **Actualizaciones**: Te mantendremos informado del progreso
- **Divulgación**: Trabajaremos contigo en la divulgación responsable
- **Reconocimiento**: Agradecemos tu contribución (a menos que prefieras anonimato)

### Divulgación Responsable

Por favor sigue estas pautas de divulgación responsable:

- Da tiempo razonable para resolver el problema antes de divulgar públicamente
- No explotes la vulnerabilidad más allá de lo necesario para demostrarla
- No accedas, modifiques o elimines datos de otros usuarios
- No realices ataques de denegación de servicio
- No instales malware o backdoors

### Recompensas

Actualmente no ofrecemos recompensas económicas por reportes de seguridad, pero:

- Reconocemos públicamente a quienes reportan vulnerabilidades (con su permiso)
- Agradecemos tu contribución para mantener seguro el proyecto
- Consideramos cada reporte seriamente

### Alcance

Las siguientes áreas están dentro del alcance:

- Código fuente en este repositorio
- Aplicación web desplegada
- Dependencias directas del proyecto
- Configuración de despliegue

Las siguientes áreas están fuera del alcance:

- Servicios de terceros integrados
- Navegadores de los usuarios
- Problemas de seguridad en versiones no soportadas

### Buenas Prácticas de Seguridad

Para usuarios del proyecto:

1. **Mantén actualizado**: Usa siempre la última versión
2. **Verifica integridad**: Verifica los hashes de las releases
3. **Reporta problemas**: Si ves algo sospechoso, repórtalo
4. **Usa HTTPS**: Siempre accede a la aplicación via HTTPS
5. **Actualiza dependencias**: Mantén tus dependencias actualizadas
